## How to Run:
1. Make sure MySQL is running in Laragon with the `movie_info` database created and imported.
2. Open terminal in the `Lab-05` directory:
   ```bash
   npm install
   node server.js
   ```
3. Open browser and visit: `http://localhost:3000`
